AI Pose Detection & Bicep Curl Counter using OpenCV + MediaPipe

   Project Overview

This project uses MediaPipe Pose and OpenCV to detect body landmarks and count bicep curls in real-time using angle calculations.
It tracks the arm movement, calculates the elbow angle, and updates the repetition count accurately.

Perfect foundation for:
   Fitness tracking apps
   Gym automation systems
   AI personal trainer
   Human pose estimation projects

 Objectives

Detect human body pose landmarks using MediaPipe.

Track arm joint angles (specifically elbow).

Map elbow angles into percentage progress of a curl.

Automatically count repetitions based on angle thresholds.

Display progress bar, percentage, FPS, and curl count in real-time.

 Features

  Real-time pose detection
  Elbow angle calculation
  Smart rep counter (counts only full curls)
  Progress bar visualization
  FPS display
  Works with webcam or video files
  Custom PoseModule class
